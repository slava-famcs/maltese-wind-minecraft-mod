# 🌪️ MalteseWind

![Minecraft Version](https://img.shields.io/badge/Paper_API-26.3-blue?style=for-the-badge&logo=minecraft)

**MalteseWind** — это атмосферный серверный плагин для Minecraft (Paper), который добавляет в игру реалистичную механику ураганного штормового ветра со скоростью 100 км/ч. Во время бури игрокам придется искать укрытие под крышей или в пещерах, иначе ветер начнет буквально сносить их с ног вместе с выброшенными предметами!

---

## ✨ Основные возможности

* 🌍 **Работа только в Оверворлде:** Бури происходят исключительно в обычном мире (`NORMAL`), не затрагивая Незер и Энд.
* 🎲 **Случайный цикл и 8 направлений:** Каждые 20–40 минут начинается шторм длительностью 3–5 минут. При каждом старте случайно выбирается одно из 8 направлений ветра (север, северо-восток, восток и т.д.).
* 🏠 **Умная система укрытий:** Молниеносная проверка крыши над головой ($O(1)$ через карту высот чанка). Пещеры, дома и даже навесы из листвы или стекла полностью защищают от ветра.
* 💨 **Физика урагана 100 км/ч:**
  * Игроков на открытой местности сносит мощным потоком воздуха.
  * Зажатый `Shift` (красться) увеличивает сопротивление ветру на 40%, позволяя медленно перебегать от укрытия к укрытию.
  * Встроенный ограничитель скорости защищает игроков от ложных срабатываний античита (`Moved too quickly!`).
  * Выброшенные на землю предметы (`ItemEntity`) подхватываются ветром и катятся по рельефу.
* 🌫️ **Визуальные и звуковые эффекты:**
  * Горизонтальные потоки частиц ветра (`CLOUD`) и густого штормового дыма (`CAMPFIRE_COSY_SMOKE`), летящие строго по вектору ветра.
  * Реалистичный объемный гул и свист бури для игроков под открытым небом, затихающий внутри помещений.
* 📊 **Динамический BossBar:** Удобный индикатор в верхней части экрана на базе Kyori Adventure API, отображающий направление ветра со стрелкой и обратный отсчет до конца бури.
* ⚙️ **Полная кастомизация:** Все таймеры, физика, частицы и звуки настраиваются в `config.yml` и перезагружаются на лету без рестарта сервера.

## 🎮 Команды и права (Permissions)

| Команда | Описание | Право (Permission) | По умолчанию |
| :--- | :--- | :--- | :--- |
| `/wind start` | Принудительно запустить штормовой ветер | `maltesewind.admin` | `op` |
| `/wind stop` | Принудительно остановить текущий шторм | `maltesewind.admin` | `op` |
| `/wind status` | Проверить статус погоды и направление ветра | `maltesewind.admin` | `op` |
| `/wind reload` | Перезагрузить настройки из `config.yml` | `maltesewind.admin` | `op` |

> 💡 Команда поддерживает удобное автодополнение клавишей `Tab`.

## ⚙️ Конфигурация (`config.yml`)

```yaml
# Временные интервалы (в минутах реального времени)
timers:
  calm-min-minutes: 20
  calm-max-minutes: 40
  storm-min-minutes: 3
  storm-max-minutes: 5

# Физика штормового ветра (обновляется каждые 2 тика)
physics:
  # Сила сдвига обычного игрока
  player-wind-strength: 0.16
  # Сила сдвига выброшенных на землю предметов
  item-wind-strength: 0.12
  # Множитель силы ветра, когда игрок зажимает Shift (0.6 = на 40% слабее)
  sneak-multiplier: 0.6
  # Максимальная горизонтальная скорость (защита от кика за Fly)
  max-wind-speed: 1.35

# Визуальные эффекты
particles:
  enabled: true
  # Количество потоков частиц за один цикл (каждые 2 тика) вокруг игрока
  amount-per-tick: 6
  # Включить густые клубы дыма (CAMPFIRE_COSY_SMOKE) помимо белых струй ветра
  enable-heavy-smoke: true

# Звуковые эффекты завывания ветра (для игроков под открытым небом)
sounds:
  enabled: true
  # Громкость звука (от 0.0 до 1.0)
  volume: 0.65

# Индикатор бури сверху экрана (BossBar)
bossbar:
  enabled: true
